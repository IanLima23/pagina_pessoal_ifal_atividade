2. Ranking de Tecnologias

  1. Tabelas HTML — Permitem organizar dados em linhas e colunas, sendo muito usadas para exibir informações estruturadas.

  2. Listas HTML — Utilizadas para organizar conteúdos em tópicos, etapas ou definições.

  3. HTML Semântico — Conjunto de tags que dão significado ao conteúdo da página, facilitando a leitura e a acessibilidade.

  4. Navegadores — Programas responsáveis por interpretar o código HTML e exibir as páginas ao usuário.

  5. HTML — Linguagem de marcação fundamental utilizada para criar a estrutura das páginas web.

3. Glossário Técnico

HTML
Linguagem de marcação utilizada para estruturar páginas web.
Define títulos, parágrafos, listas, tabelas e links.
Navegador
Browser
Software utilizado para acessar e visualizar páginas da internet.
Tag
Comando utilizado no HTML para marcar e estruturar conteúdos.
Lista
Conjunto de itens organizados de forma ordenada, não ordenada ou por definição.
Tabela
Estrutura utilizada para organizar dados em linhas e colunas.
Link
Elemento que permite a navegação entre páginas ou seções.
URL
Endereço que identifica um recurso na internet.
Semântica
Uso de tags que descrevem corretamente o significado do conteúdo.
